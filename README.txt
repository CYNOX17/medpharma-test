MedPharma 2.0 (offline-capable PWA)

Files: index.html, manifest.json, service-worker.js

Install: upload all files to the same HTTPS hosting folder (for example GitHub Pages), open the site in Chrome, then choose Add to Home screen / Install app. Service worker/offline mode generally requires HTTPS or localhost.

Login defaults preserved from the previous version: username Nahiyan4259, password 74259. Change the password after first login.

Important data note: app data is stored in this browser on this device. Use Profile > Data Backup & Restore regularly. Restoring replaces current local data. Never use a single local-only copy as the only record for a real pharmacy.

This is a small-store starter app, not a certified pharmacy/POS/accounting system. Verify calculations and backups with test data before relying on it for real transactions.
